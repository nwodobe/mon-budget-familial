Supprimer mon compte Mon Budget Familial

Cette page explique comment supprimer votre compte cloud Mon Budget Familial et les données cloud qui lui sont associées.

Depuis l’application :
  1. Ouvrez Plus.
  2. Accédez à Compte puis Supprimer mon compte.
  3. Vérifiez le compte connecté.
  4. Confirmez la suppression définitive.

Données supprimées

La suppression du compte supprime l’identité de connexion et les données cloud rattachées à ce compte, notamment les paramètres du foyer, revenus, charges, dépenses, enveloppes, mouvements d’épargne, objectifs, provisions et autres données budgétaires synchronisées.

Données locales

Les données enregistrées uniquement sur un appareil peuvent être effacées séparément depuis la zone sensible des réglages de l’application. Après suppression du compte, l’application peut également effacer les données locales de l’appareil utilisé pour confirmer la demande.

Attention : la suppression d’un compte est définitive. Exportez une sauvegarde avant de confirmer si vous souhaitez conserver une copie de vos données.
